# JkDefrag

| | |
|---|---|
| Manifest | [`bucket/JkDefrag.json`](../../bucket/JkDefrag.json) |
| Upstream | [JkDefrag Portable](https://portableapps.com/apps/utilities/jkdefrag_portable) (PortableApps.com; JkDefrag by Jeroen Kessels) |
| Install | `scoop install gesu/JkDefrag                 # runs elevated (UAC prompt)` |

Defragmenter and optimizer, the open source predecessor of MyDefrag. Without options it puts folders at the start of the disk, regular files after them and *SpaceHogs* (big, rarely used files; add your own with `-u "mask"`) at the end; `-a 7` … `-a 11` sort files by name, size, last access, last change or creation time, and `-a 6` moves them to the end of the disk. **3.36 (2008) is the last version**: from 4.0 it became the closed-source MyDefrag, also abandoned. The author's site is gone; the [sources](https://sourceforge.net/projects/winpenpack/files/winPenPack_Suites/sources/4.4/Programs/JkDefrag/JkDefrag-src-3.36.zip) survive in winPenPack's SourceForge project. The binaries come from PortableApps.com's JkDefrag Portable 3.36 Rev 2 (an NSIS package that 7-Zip unpacks); `extract_dir` keeps only `App\JkDefrag`, without the PortableApps launcher. Its hash matches the SHA-1 and MD5 that SourceForge lists; the executables carry J.C. Kessels' version information (3.36). Command: `jkdefrag` (`JkDefrag64.exe` on 64-bit Windows, `JkDefrag.exe` on 32-bit); it asks for admin rights (UAC) and, **without a drive letter, processes all fixed drives**. The *JkDefrag* shortcut opens PortableApps.com's small AutoIt GUI (`JkDefragGUI.exe`, GPL): pick drives, then *Analyze*, *Defragment* or *Defragment and Optimize*. The GUI has `#RequireAdmin` and finds `JkDefrag64.exe` and its `languages` folder relative to the working folder; started without admin rights it restarts itself elevated in `System32` and fails (*The required JkDefrag64.exe cannot be found*). PortableApps.com hides this because its launcher is already elevated. Here `post_install` sets the *Run as administrator* flag on the shortcut (`SLDF_RUNAS_USER` in the `.lnk` header), so Windows elevates it at once and keeps the shortcut's working folder. `scoop reset` recreates the shortcut without the flag; `scoop update JkDefrag -f` sets it again. Some antivirus programs flag compiled AutoIt scripts. No `checkver`: nothing new is expected. License: GPL v2 or later (source headers). Not in the [Extras](https://github.com/ScoopInstaller/Extras) bucket.
