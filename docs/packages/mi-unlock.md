# Mi-Unlock

| | |
|---|---|
| Manifest | [`bucket/Mi-Unlock.json`](../../bucket/Mi-Unlock.json) |
| Upstream | [miui.com/unlock](https://www.miui.com/unlock/) (Xiaomi, freeware) |
| Install | `scoop install gesu/Mi-Unlock` |

Mi Unlock (Mi Flash Unlock), Xiaomi's official bootloader unlock tool for Xiaomi, Redmi and POCO phones; *Mi Unlock* shortcut in Scoop Apps. It only finishes what Xiaomi allowed: on HyperOS you first apply in the Xiaomi Community app (*Me → Unlock bootloader*) and bind the account on the phone (*Developer options → Mi Unlock status*, over mobile data); unlocking erases the phone. **English build**: the download page [`www.miui.com/unlock/download.html`](https://www.miui.com/unlock/download.html) links only the Chinese archive `miflash_unlock_<version>.zip`, whose `config/app_info` says `"language": "zh", "region": "CN"` and logs in with `zh_CN`; the same CDN folder also holds `miflash_unlock_en_<version>.zip` (`"language": "en"`, no region), which the manifest uses. [`en.miui.com/unlock/download_en.html`](https://en.miui.com/unlock/download_en.html) still links 6.5.224.28. `checkver` reads the version from the Chinese page and autoupdate builds the `_en_` URL, so Excavator fails visibly if Xiaomi stops publishing the English build. Portable ZIP, no installer; `miflash_unlock.exe` is signed by Beijing Xiaomi Intelligent Technology. The archive also carries `fastboot.exe`, `fastboot_one.exe` and the Xiaomi USB driver with its installers (`MiUsbDriver.exe`, `driver_install*.exe`); none of them is put on the `PATH`, so they do not shadow `adb`'s `fastboot`. The Xiaomi driver lists only Xiaomi and Google IDs, not MediaTek's `VID_0E8D`, so a MediaTek phone in fastboot mode (`PID_201C`) stays unrecognised: the notes say so, and the manifest [suggests](https://github.com/ScoopInstaller/Scoop/wiki/App-Manifests#optional-properties) `Google-USB-Driver`, whose *Android Bootloader Interface* is then bound by hand. There is no separate global build: the English archive is the one without a region (`"region": ""`), like the 6.5.224.28 on Xiaomi's global page; the CDN has no `_global_`, `_in_`, `_ru_`, `_eea_` or `_intl_` variant. `config.ini` and `history.ini`, which the tool writes next to its exe, are copied to the persist folder in `pre_uninstall` (which also runs on update) and back in `pre_install`. Decline the tool's own update offer; use `scoop update`. The same English archive is on `miuirom.xiaomi.com`, listed in [`mirrors.psd1`](../../mirrors.psd1) for [`Use-Mirror.ps1`](../mirrors.md#installing-from-a-mirror). Not in Scoop's official buckets.
