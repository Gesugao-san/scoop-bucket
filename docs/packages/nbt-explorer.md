# NBT-Explorer

| | |
|---|---|
| Manifest | [`bucket/NBT-Explorer.json`](../../bucket/NBT-Explorer.json) |
| Upstream | [jaquadro/NBTExplorer](https://github.com/jaquadro/NBTExplorer) |
| Install | `scoop install gesu/NBT-Explorer` |

Runs on the .NET Framework 4 that ships with Windows. The bundled command-line `NBTUtil` needs .NET Framework 3.5: Windows offers to download it on first run, or enable it with `DISM /Online /Enable-Feature /FeatureName:NetFx3 /All` (admin). Also available in the [games](https://github.com/Calinou/scoop-games) bucket as `nbtexplorer`.
