| Upstream | [tryashtar/nbt-studio](https://github.com/tryashtar/nbt-studio) |
| Install | `scoop install gesu/NBT-Studio` |

Needs the [.NET 6 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/6.0) x64: the manifest [suggests](https://github.com/ScoopInstaller/Scoop/wiki/App-Manifests#optional-properties) `versions/windowsdesktop-runtime-6.0` from Scoop's [Versions](https://github.com/ScoopInstaller/Versions) bucket (needs admin), or use `winget install Microsoft.DotNet.DesktopRuntime.6`. Upstream has no [releases](https://github.com/tryashtar/nbt-studio/releases) since v1.15.3. File associations: [see below](../conventions.md#file-associations).
